# Changelog

## 4.0.0 — 2026-08-14

- разделены постоянный Matrix `server_name` и API-домен через `.well-known` delegation;
- удалён пустой whitelist, который блокировал федерацию;
- добавлено управление публичной и ограниченной федерацией;
- отключена небезопасная открытая регистрация без проверки;
- закреплены версии контейнеров;
- обновлена схема MAS и включён MAS admin API;
- добавлены Ketesa Admin, Element Admin и ntfy;
- добавлена опциональная маршрутизация Docker через Xray/VLESS;
- добавлены backup, диагностика, обновление с предварительным backup и откат Synapse-конфига;
- добавлены безопасная запись `.env`, продление сертификата Coturn, retries и статические тесты/CI;
- Element Web и Element Call не устанавливаются.

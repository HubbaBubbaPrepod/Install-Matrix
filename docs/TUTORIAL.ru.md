# Я сделал установщик Matrix Synapse одной командой

> [English version](TUTORIAL.md)

Запуск Matrix homeserver — это не просто запуск Synapse. Для практичного развёртывания нужны PostgreSQL, HTTPS, обнаружение федерации, TURN, firewall, backup и понятное обновление. Опциональные MAS и MatrixRTC добавляют новые компоненты.

Install-Matrix объединяет установку на одном VPS в один проверяемый Bash-релиз, оставляя создаваемые файлы доступными в `/root/matrix-server`.

## Цели проекта

1. Пользователь должен понять требования DNS и портов до запуска.
2. Безопасный путь должен использоваться по умолчанию, а расширенные возможности — включаться явно.
3. После неудачного обновления должны оставаться rollback образов и backup базы.
4. Автоматизация не должна передавать секреты в командной строке.
5. Каждая поддерживаемая конфигурация должна рендериться в CI.

## Архитектура

Nginx завершает HTTPS и направляет запросы сервисам на loopback. Synapse и MAS используют отдельные базы PostgreSQL. Coturn и LiveKit используют host network только для необходимых медиапортов. `.well-known` отделяет удобные Matrix ID от имени API-сервера.

## Надёжность

Установщик создаёт PostgreSQL dump в custom format, архивирует signing keys и конфигурацию, записывает SHA-256 и умеет восстанавливать стек. Управляемое обновление сохраняет старый набор образов и автоматически откатывает его при ошибке health checks.

## Безопасность

Релизные файлы имеют checksum, Xray installer закреплён commit и SHA-256, Actions используют полные commit SHA, текущий SSH-порт сохраняется до включения UFW, а пароль администратора для автоматизации читается из защищённого файла.

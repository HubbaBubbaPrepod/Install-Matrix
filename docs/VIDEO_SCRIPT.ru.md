# Сценарий 60-секундной демонстрации

> [English version](VIDEO_SCRIPT.md)

| Время | Изображение | Голос/подпись |
|---:|---|---|
| 0–5 с | Архитектура и название | Разверните полноценный Matrix homeserver на обычном VPS |
| 5–12 с | Проверка checksum релиза | Начинаем с неизменяемого проверенного релиза |
| 12–25 с | Меню и ввод доменов | Выбираем домены и режим регистрации |
| 25–40 с | Ход установки | Synapse, PostgreSQL, Nginx, TLS и TURN настраиваются вместе |
| 40–50 с | Health report | Критические endpoints проверяются автоматически |
| 50–57 с | Вход и чат в Matrix-клиенте | Подключите любой совместимый Matrix-клиент |
| 57–60 с | GitHub URL | Install-Matrix — простой self-hosting на одном VPS |

Не показывайте в записи настоящие секреты и IP. Используйте одноразовый demo-сервер и не заявляйте время установки без опубликованного измерения.

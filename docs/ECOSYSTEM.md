# Matrix ecosystem submission checklist

> [Русская версия](ECOSYSTEM.ru.md)

The long-term distribution goal is inclusion in the Matrix ecosystem catalogue.

- [x] OSI-compatible license
- [x] tagged semantic release workflow
- [x] checksum-verifiable installer
- [x] documented architecture and security policy
- [x] backup, restore, upgrade, rollback and uninstall
- [x] CI across declared Ubuntu/Debian userspaces
- [x] disposable-VM E2E workflow
- [x] public issue and contribution templates
- [ ] publish v4.1.0 and complete a documented production E2E run
- [ ] establish a public support Matrix Space/room
- [ ] collect two independent production user reports
- [ ] submit a concise distribution entry to the Matrix website repository

Suggested description:

> Install-Matrix is a single-VPS interactive and non-interactive installer for Synapse, PostgreSQL, Nginx, Let's Encrypt and Coturn, with optional MAS and MatrixRTC. It focuses on a fast, understandable Ubuntu/Debian deployment with backup, restore and rollback built in.

# Code of Conduct

> [Русская версия](CODE_OF_CONDUCT.ru.md)

## Our standard

Be respectful, specific and patient. Welcome newcomers, critique technical decisions rather than people, respect privacy and never pressure anyone to disclose production credentials.

Harassment, discrimination, threats, doxxing, credential publication and unauthorized security testing are unacceptable.

## Enforcement

Report conduct concerns privately to the repository maintainer through the contact method on their GitHub profile. Maintainers may edit or remove content, lock conversations or restrict participation when necessary to protect the community.

This policy applies in repository issues, pull requests, discussions and any official Install-Matrix community rooms.

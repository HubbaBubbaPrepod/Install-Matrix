# Security Policy

Пожалуйста, не создавайте публичный issue с уязвимостью, рабочими паролями, токенами, Matrix registration secret, VLESS URI или содержимым `/root/matrix-server`.

Сообщите владельцу репозитория приватно через GitHub Security Advisories: **Security → Advisories → Report a vulnerability**.

В сообщении укажите затронутую версию, условия воспроизведения, возможное влияние и безопасный способ проверки. Перед отправкой удалите реальные домены, IP-адреса и секреты.

Поддерживается актуальная ветка `main`. Скрипт предназначен для чистых Ubuntu/Debian-серверов; нестандартные Docker, Nginx, UFW или Xray-конфигурации требуют отдельной проверки администратора.

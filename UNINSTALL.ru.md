# Удаление

> [English version](UNINSTALL.md)

Поддерживаются два режима удаления.

## Удалить сервисы, сохранить данные

```bash
sudo ./install-matrix.sh uninstall --keep-data
```

Команда останавливает и удаляет Compose-контейнеры, созданные конфигурации Nginx и правила приложений в firewall, но сохраняет `/root/matrix-server` для восстановления.

Для повторной установки используйте тот же скрипт и базовую команду `install`. Существующие данные и секреты БД будут использованы повторно.

## Удалить всё

```bash
sudo ./install-matrix.sh uninstall --purge
```

Установщик:

1. создаёт финальный backup базы и конфигурации;
2. экспортирует его в `/root/install-matrix-final-backup-<timestamp>.tar.gz`;
3. удаляет контейнеры, созданные файлы Nginx и правила UFW;
4. проверяет точный путь и удаляет `/root/matrix-server`.

Финальный архив не содержит `media_store`. Скопируйте медиа отдельно до purge. Сертификаты Let's Encrypt сохраняются, поскольку могут использоваться другими сервисами; удаляйте их через `certbot delete` только после проверки.

Docker, Nginx, Certbot и UFW не удаляются: они могут быть нужны другим приложениям.
